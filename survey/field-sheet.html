Gilmorehill field sheet — four destinations

step free / ramp / hand rail / tact / lit / seat: Y or N  ·  surface: A=asphalt, P=paving_stones, C=concrete, G=gravel, R=grass, K=cobbles, O=other  ·  cond: G=good, U=uneven, P=poor  ·  kerb: F=flush, L=lowered, R=raised, N=none  ·  door type (entrances): A=automatic, M=manual, H=heavy, R=revolving  ·  grad %: phone level, steepest point, degrees × 1.75  ·  width: metres, at the NARROWEST point  ·  ⚠ = steps, count them and look for a ramp

The single letters above are understood by npm run survey:check -- --fix, which expands them for you — the same letter is read differently in each column, so G in cond is good while G in surface is gravel. Leave a cell blank if you did not check it: blank means "unknown", which is honest. Do not guess. step free and width are the two that matter most.
